# Tegassen Autobell

A **Digital Bell System** designed specifically for Catholic churches. This system provides an automated and customizable solution for managing church bells, integrating modern technology with tradition.

## Features

- **Automated Scheduling**: Set schedules for bell ringing for different times of the day, liturgical seasons, or special events.
- **Customizable Sounds**: Upload or select from pre-loaded bell sounds to suit the church's needs.
- **User-friendly Interface**: Manage the system easily via a web or mobile application.
- **Multi-language Support**: Support for multiple languages for broader accessibility.
- **Cross-platform**: Built using TypeScript, Kotlin, and Objective-C to ensure compatibility across platforms.

## Installation

### Prerequisites
1. Ensure you have the following installed:
   - [Node.js](https://nodejs.org/) (for TypeScript support)
   - [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/javase-downloads.html) (for Kotlin)
   - A compatible operating system (Windows, macOS, or Linux)

### Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/Gifted87/TegassenAutobell.git
   ```
2. Navigate to the project directory:
   ```bash
   cd TegassenAutobell
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Build the project:
   ```bash
   npm run build
   ```
5. Start the application:
   ```bash
   npm start
   ```

---

## Usage

1. Access the application through your browser or mobile device.
2. Navigate to the **Schedule** section to set up bell ringing times.
3. Customize the bell sounds in the **Sounds** section.
4. Monitor and adjust settings as needed.
